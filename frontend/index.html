校园失物招领小程序

智能匹配 · 快速找回 · 物归原主

项目介绍

这是一个基于微信小程序开发的校园失物招领平台，包含完整的前端代码结构。

项目结构

shiwuzhaoling/
├── app.json # 小程序配置文件
├── sitemap.json # 小程序搜索配置
├── pages/
│ ├── login/ # 登录页面
│ ├── home/ # 首页
│ ├── publish/ # 发布页面
│ ├── message/ # 消息页面
│ │ ├── system/ # 系统通知
│ │ ├── match/ # 匹配通知
│ │ ├── reply/ # 回复通知
│ │ └── settings/ # 消息设置
│ └── profile/ # 个人中心
└── README.md # 项目说明文档

功能说明

1. 登录页面

  • 微信一键登录
  • 游客模式浏览
  • 隐私政策提示

2. 首页

  • 寻物启事/失物招领标签切换
  • 物品分类筛选
  • 搜索功能
  • 物品卡片点击

3. 发布页面

  • 发布寻物启事和失物招领
  • 图片上传
  • 表单验证
  • 联系方式选择

4. 消息页面

  • 系统通知
  • 匹配通知
  • 回复通知
  • 消息设置（开关控制）

5. 个人中心

  • 用户信息展示
  • 发布记录统计
  • 信用等级系统
  • 功能菜单

如何使用

  1. 在微信开发者工具中打开项目
  2. 选择"导入项目"
  3. 填写项目名称和项目路径
  4. 选择小程序AppID（可以使用测试号）
  5. 点击"导入"
  6. 编译并预览

技术实现

  • 使用微信小程序原生框架：WXML + WXSS + JavaScript
  • 页面跳转：使用 wx.navigateTo、wx.switchTab 等API
  • 数据存储：使用 wx.setStorageSync、wx.getStorageSync
  • 图片选择：使用 wx.chooseImage
  • 网络请求：使用模拟数据，预留了真实API接口

注意事项

重要：本项目是微信小程序前端代码，需要在微信开发者工具中打开才能正常预览和使用。本地服务器只能展示项目结构和说明，无法运行小程序功能。

请按照上述"如何使用"的步骤，在微信开发者工具中导入并预览项目。
