## 二、核心页面清单

### 2.1 页面结构（来源：PPT 前端展示层 + 阶段三）

根据 PPT「上传、搜索、结果展示及个人中心」及阶段三「结果页、推荐列表页、地图展示」，梳理如下：

| 页面 | 路径建议 | 核心功能 | 备注 |
|------|----------|----------|------|
| **首页** | `/` 或 `/home` | 最新发布列表、快捷发布入口、全局搜索 | 
| **发布页** | `/publish` | 选择寻物/招领、上传图片、填写信息、LBS 选点 | 
| **搜索页** | `/search` | 以图搜图入口、以文搜文输入框、筛选条件 | 
| **结果列表** | `/search/result` | 匹配结果卡片、相似度标签、分页/无限滚动 |
| **物品详情** | `/item/:id` | 图片、描述、地点、时间、联系按钮、地图、底部「相关失物推荐」 | 
| **个人中心** | `/profile` | 我的发布、我的收藏、消息通知、设置 | 
| **登录/注册** | `/auth/login` | 手机号/学号登录、注册 |
| **消息/沟通** | `/messages` | 与拾获者/失主的站内消息（若采用站内消息方案） | 

### 2.2 关键交互说明

| 交互 | 页面 | 行为 | 备注 |
|------|------|------|------|
| 上传图片 | 发布页 | 支持拍照 / 相册选择，支持多图，可预览删除 | 
| 自动识别反馈 | 发布页 | 上传后显示 loading，识别完成后自动填充物品类型、文字信息 | 
| 以图搜图 | 搜索页 | 点击相机图标，拍照/选图后发起搜索 | 
| 以文搜文 | 搜索页 | 输入框输入关键词，支持联想/历史记录 | 
| 相关推荐 | 详情页底部 | 展示「可能相关的失物」，点击可跳转详情 |
| 地图展示 | 详情页 | 展示丢失/拾取地点的地图标注 | 
| 移动端适配 | 全站 | 响应式布局，适配手机端操作 |

## 三、UI 设计规范

### 3.1 设计原则

| 原则 | 描述 |
|------|------|
| **清晰** | 信息层级明确，寻物/招领类型、状态一眼可辨 |
| **高效** | 减少操作步骤，上传即识别、搜索即出结果 |
| **信任** | 界面简洁专业，突出匹配度、时间等可信信息 |
| **适配** | 兼顾 PC 与移动端，校园用户以手机为主 |

### 3.2 色彩规范（建议）

> **补充说明**：PPT 未给出具体色系，以下为常见校园/公益类产品配色，可替换为团队品牌色。

| 用途 | 色值 | 说明 |
|------|------|------|
| 主色 | `#1890FF` | 品牌蓝，主按钮、链接、选中态 |
| 寻物 | `#FA8C16` | 橙色，区分寻物类 |
| 招领 | `#52C41A` | 绿色，区分招领类 |
| 成功 | `#52C41A` | 已归还、操作成功 |
| 警告 | `#FAAD14` | 待处理、提醒 |
| 错误 | `#FF4D4F` | 失败、危险操作 |
| 中性灰 | `#8C8C8C` | 辅助文字 |
| 背景 | `#F5F5F5` | 页面背景 |

### 3.3 字体规范（建议）

| 场景 | 字号 | 字重 | 示例 |
|------|------|------|------|
| 大标题 | 20–24px | Bold | 页面标题 |
| 中标题 | 16–18px | SemiBold | 卡片标题、物品名称 |
| 正文 | 14px | Regular | 描述、地点、时间 |
| 辅助 | 12px | Regular | 相似度、状态标签、时间戳 |

### 3.4 组件库建议

| 技术栈 | 推荐库 | 说明 |
|--------|--------|------|
| Vue | Element Plus / Vant | 后台用 Element，移动端用 Vant |
| React | Ant Design / Ant Design Mobile | 企业级组件，文档完善 |
| 微信小程序 | Vant Weapp | 若做小程序版本 |
