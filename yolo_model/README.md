# YOLO 视觉识别模块

本模块负责智能校园失物招领系统的物品视觉识别功能，基于 YOLO11 目标检测算法，实现对校园常见失物的自动识别与定位。

## 项目概述

本模块已成**功训练并部署了针对三类校园常见失物的 YOLO11 目标检测模型，支持实时图像**识别与批量推理。

## 识别类别

| 类别      | 英文标签     | 说明                  |
| ------- | -------- | ------------------- |
| 钥匙      | keys     | 各类钥匙（门禁卡、宿舍钥匙、车钥匙等） |
| 身份证/校园卡 | id\_card | 身份证、学生证、校园卡等证件类物品   |
| 眼镜      | glasses  | 近视眼镜、太阳镜等各类眼镜       |

### 训练模型

```bash
python train.py
```

训练参数说明：

- `epochs`: 50 (训练轮数，可根据数据量调整至 100-300)
- `imgsz`: 640 (输入图像尺寸)
- `batch`: 16 (批次大小，显存不足时可降至 8 或 4)
- `name`: campus\_lost\_v1 (训练结果保存目录)

### 实时检测

打开 `realtime_detect.ipynb`，运行相关单元格即可启动摄像头实时检测。

### 训练配置

| 参数   | 值       | 说明               |
| ---- | ------- | ---------------- |
| 模型   | YOLOv8n | 极小杯版本，速度快，适合实时检测 |
| 训练轮数 | 50      | 可根据验证集表现调整       |
| 图像尺寸 | 640x640 | 输入图像统一尺寸         |
| 批次大小 | 16      | 每批处理图像数量         |

## 技术栈

- **深度学习框架**: PyTorch
- **目标检测模型**: YOLOv8n (Ultralytics)
- **数据标注**: Roboflow / LabelImg
- **图像处理**: OpenCV, Pillow

## 注意事项

1. Windows 系统下训练时，必须使用 `if __name__ == '__main__'` 包裹训练代码
2. 首次运行会自动下载预训练模型 `yolo11n.pt`
3. 如遇显存不足，请减小 `batch` 参数或使用 CPU 训练
4. 训练结果保存在 `runs/detect/campus_lost_v1/` 目录下
